## Как слить

PR #2–#12 идут **цепочкой**: каждая ветка построена на предыдущей и содержит всё, что было до неё.

- **Аккуратно**: сливать по порядку, #2 → #3 → … → #12. Тогда история `main` повторяет этапы. Конфликтов быть не должно: после слияния очередного PR следующий содержит только свои изменения.
- **Быстро**: слить сразу #12. В `main` попадёт всё с #2 по #12, остальные PR GitHub закроет сам как уже слитые.
- #1 (план мода) не зависит от цепочки, его можно слить в любой момент.

Если хочется продолжить, ничего не сливая, работайте прямо от `feature/echo-act1`: там самая свежая версия.

## Как проверить, что всё работает

```
gradlew runGametest
```
Игровые тесты: сейчас их 45, все проходят.

```
gradlew runClient
```
Обычная игра с модом.

```
gradlew runTour
```
Фототур: игра сама проходит механики и сохраняет скриншоты в `run/screenshots/tour`. Короткие режимы включаются пустым файлом в `run/`: `tour-flight-only`, `tour-echo-only`, `tour-lunar-only`, `tour-survival-only`, `tour-moon-only`, `tour-models-only` (после прогона файл удалить).

```
python tools/check_assets.py
```
Проверка ресурсов: у каждого блока и предмета есть модель, текстура, перевод и таблица добычи.

## Где что лежит

- [README.md](../README.md) — сборка, устройство кода, как работаем вдвоём.
- [docs/ECHO.md](ECHO.md) — сценарий «Эхо» и решения по нему.
- [docs/SOUNDS.md](SOUNDS.md) — все звуки мода и подсказки для ElevenLabs, чтобы заменить любой звук своим.
- `tools/` — всё, что рисуется и собирается скриптами, а не руками:
  - `textures/generate.py` — пиксельные текстуры;
  - `textures/planets.py` — Земля, Луна, Солнце, вид с орбиты;
  - `textures/cockpit.py` — кабина для полёта от первого лица;
  - `models/generate.py` — объёмные модели (ракета, скафандр, луноход) и проекты Blockbench в `blockbench/`;
  - `sounds/synthesize.py` — звуки (нужны numpy и ffmpeg).

Правило: текстуры, модели и звуки не правим в редакторах поверх сгенерированных. Правим скрипт и перезапускаем. Если что-то удобнее доделать руками (например, модель в Blockbench), уберите это из генератора, чтобы правки не затёрлись.

## Что не проверено живым игроком

- Звуки на слух: их проверяли только по спектрограммам. Если какой-то звучит плохо, замените его по [docs/SOUNDS.md](SOUNDS.md).
- Насколько страшно на Луне на самом деле и не надоедают ли звуки за долгую игру.
- Дорога до Эха на луноходе и луноход с пассажиром в мультиплеере.
- Частота метеоритов и лунотрясений на долгой игре.
- Проекты `.bbmodel` открываются в Blockbench (собраны по его формату, но в самом Blockbench не открывались).

## Что дальше: этап 0.9 «Расшифровка»

По [docs/ECHO.md](ECHO.md):

- Осколок Эха в анализаторе даёт новый тип очков науки — **«Сигнал»**.
- Ветка исследований «Сигнал» и **радиотелескоп**. В конце ветки в небе появляется следующая цель — Марс.
- **Плёнка «Зари»** из бортового магнитофона: что услышал экипаж перед тем, как пропасть.
- **Кристаллиды** в лавовых трубках Луны: медленные кристаллические существа, тянутся к сигналу, не враги.
- Озвучка ЦУП субтитрами с тонами связи (тоны уже есть: `flight.quindar_in` / `quindar_out`).

Задел уже есть: состояние сюжета хранится в `EchoSite` (мир Луны) и в отметках `SpaceProgram` (`echo_signal`, `zarya_found`, `echo_contact`), события — в `EchoEvents`.
